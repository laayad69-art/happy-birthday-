## 📸 معاينة المشروع

```
[خلفية Binary Rain وردية وذهبية]
        ↓
   عداد تنازلي 3 → 2 → 1
        ↓
   سلايد شو للصور + رسائل حب طايرة
        ↓
  ✨ Happy Birthday Mariam ✨
   مع موسيقى وقلوب وتأثيرات
```

## ✨ المميزات

| الميزة | التفاصيل |
|--------|----------|
| 🎆 Binary Rain | مطر من 0 و1 بألوان وردي، ذهبي، بنفسجي في الخلفية |
| ⏳ عداد تنازلي | أرقام 3→2→1 بخط Cinzel Decorative فاخر |
| 🖼️ سلايد شو | 3 صور تنتقل تلقائياً مع تأثيرات انتقال سلسة |
| 💌 رسائل حب | "I love you Mariam" تطير على الشاشة باستمرار |
| 🎵 موسيقى | أغنية Happy Birthday تشتغل أوتوماتيك (Web Audio) |
| 💖 قلوب طايرة | إيموجي وقلوب تتحرك بعد ظهور الرسالة الرئيسية |
| 📱 متوافق | يشتغل على موبايل وكمبيوتر بدون مشاكل |
| 📦 ملف واحد | الصور والموسيقى كلها مدمجة داخل الـ HTML |

## 🚀 طريقة التشغيل

### تشغيل محلي
```bash
# فتح الملف مباشرة في المتصفح
double-click على index.html
```

### نشر على الإنترنت — Netlify (مجاني وسريع)
```
1. افتح: netlify.com/drop
2. اسحب ملف index.html وأفلته في الصفحة
3. احصل على رابط جاهز فوراً ✅
```

### نشر على GitHub Pages
```bash
# 1. أنشئ repository جديد على GitHub
# 2. ارفع الملف index.html
# 3. Settings → Pages → Deploy from main branch
# 4. رابطك: https://username.github.io/repo-name
```
